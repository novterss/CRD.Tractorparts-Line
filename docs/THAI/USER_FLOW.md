# กระบวนการใช้งาน (User Flow) - CRD Tractor Parts

เอกสารนี้อธิบายการไหลของระบบ (Flow) ตั้งแต่ลูกค้าทักแชท ไปจนถึงการปิดการขายโดยอัตโนมัติ 100% ด้วย AI

## 1. การทักทายและเมนูหลัก (Welcome Flow)
- ผู้ใช้อัพเพื่อน หรือทักแชทเข้ามา
- บอทส่งข้อความทักทาย พร้อมแนบ **Quick Reply** 4 ตัวเลือก:
  1. ดูสินค้า (เรียก Flex Message)
  2. สั่งซื้อผ่านเว็บ (เรียกเปิด LIFF App)
  3. ปรึกษาช่าง (ระบบ AI Text)
  4. ติดต่อแอดมิน (ข้อมูลร้านค้า)

## 2. กระบวนการสั่งซื้อผ่าน LIFF (E-Commerce Flow)
- ผู้ใช้กดปุ่ม **"🌐 สั่งซื้อผ่านเว็บ"**
- ระบบเปิด LIFF App ขนาด Full-screen (ใช้โทนสี Premium Dark Theme)
- ลูกค้ากด **"ใส่ตะกร้า"** ระบบจะคำนวณยอดเงินรวมและแสดงใน Floating Cart
- ลูกค้ากด **"ชำระเงิน"**
- LIFF SDK เรียกฟังก์ชัน `liff.sendMessages` เพื่อพ่นสรุปออเดอร์ (บิลรายการ + ยอดเงิน + เลขบัญชีร้าน) กลับเข้าไปในหน้าแชท LINE แบบอัตโนมัติ

## 3. กระบวนการตรวจสอบสลิปอัตโนมัติ (AI Slip Verification Flow)
- ลูกค้าทำการโอนเงิน และ **อัปโหลดรูปภาพสลิป** เข้าไปในแชท
- บอทตรวจจับ `event.message.type === 'image'`
- บอทดึงข้อมูลตะกร้าสินค้าใน Memory (`userCarts`) มาตรวจสอบยอดที่ต้องชำระ
- บอทโหลดรูปภาพจาก LINE Server แปลงเป็น Buffer
- ส่งภาพไปให้ **Gemini 1.5 Flash (Vision Mode)** พร้อม Prompt ให้สกัดตัวเลขยอดโอนจากรูปภาพ
- **กรณีที่ 1 (ถูกต้อง):** AI ตอบยืนยัน -> บอทเคลียร์ตะกร้า -> บอทส่ง Push Notification ไปยัง LINE ของแอดมินทันที
- **กรณีที่ 2 (ไม่ถูกต้อง):** AI แจ้งว่ายอดเงินไม่ตรง หรือไม่ใช่สลิป -> บอทแจ้งให้ลูกค้าตรวจสอบอีกครั้ง

## 4. กระบวนการปรึกษาปัญหาทางเทคนิค (AI Mechanic Flow)
- ลูกค้าพิมพ์คำถามโดยมีคำว่า **"ถาม"** นำหน้า
- บอทดึงประวัติการสนทนา (Chat History) ของลูกค้ารายนั้น
- ส่งคำถามให้ Gemini 1.5 Flash วิเคราะห์หาสาเหตุและวิธีแก้ไขปัญหารถไถ
- บอทตอบกลับลูกค้าด้วยข้อความที่เป็นมืออาชีพ

## 5. กระบวนการสลับการคุยกับคน (Hybrid Handoff Flow)
- หากลูกค้าพิมพ์ข้อความทั่วไป (เช่น "ขอโทษทีส่งผิด", "ลดได้ไหม") ที่ไม่เข้าเงื่อนไข Keyword และไม่ได้นำหน้าด้วย "ถาม"
- บอทจะเข้าโหมด **Stand Down (ข้ามการตอบกลับ)**
- แอดมินที่เป็นมนุษย์สามารถเห็นข้อความผ่านจอ LINE OA Manager และพิมพ์โต้ตอบกับลูกค้าได้ทันทีโดยที่บอทไม่เข้ามาแทรก
