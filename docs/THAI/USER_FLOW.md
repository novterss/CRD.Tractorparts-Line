# กระบวนการใช้งาน (User Flow) - CRD Tractor Parts

เอกสารนี้อธิบายการไหลของระบบ (Flow) ตั้งแต่ลูกค้าทักแชท ไปจนถึงการปิดการขายโดยสมบูรณ์

## 1. การทักทายและเมนูหลัก (Welcome Flow)
- ผู้ใช้อัพเพื่อน หรือทักแชทเข้ามา
- บอทส่งข้อความทักทาย พร้อมแนบ **Quick Reply** 4 ตัวเลือก:
  1. ดูสินค้า (เรียกแคตตาล็อก Flex)
  2. สั่งซื้อผ่านเว็บ (เรียกเปิด LIFF App)
  3. ปรึกษาช่าง (ระบบ AI Text)
  4. ติดต่อแอดมิน (ข้อมูลร้านค้า)

## 2. กระบวนการสั่งซื้อและชำระเงิน (E-Commerce Flow)
- ผู้ใช้กดปุ่ม **"🌐 สั่งซื้อผ่านเว็บ"**
- ระบบเปิด LIFF App ขนาด Full-screen (ใช้โทนสี Premium)
- ลูกค้ากด **"ชำระเงิน"**
- LIFF SDK ส่งข้อความสั่งซื้อกลับเข้าแชท
- **ระบบคำนวณยอดเงินและสร้าง PromptPay QR Code** ส่งกลับให้ลูกค้าสแกนจ่ายทันที

## 3. กระบวนการตรวจสอบสลิปและเลื่อนขั้น VIP (Approval & CRM Flow)
- ลูกค้า **อัปโหลดรูปภาพสลิป** เข้าไปในแชท
- บอทตอบกลับว่า "ได้รับสลิปแล้ว รอตรวจสอบ"
- บอทบันทึกสลิป และ **ส่ง Push Notification แจ้งเตือนแอดมิน** ทันที
- แอดมินเข้าสู่ระบบได้ 2 ทาง:
  - ทางที่ 1: พิมพ์ `/admin fatmonkey` ในแชท เพื่อกดอนุมัติสลิปผ่าน LINE 
  - ทางที่ 2: เปิดหน้าเว็บ Admin Dashboard (กรอก PIN: `fatmonkey`) เพื่อดูสลิปและกดอนุมัติ
- เมื่ออนุมัติ **ลูกค้าจะได้รับแต้มสะสมอัตโนมัติ (100 บาท = 1 แต้ม)**
- ลูกค้าสามารถพิมพ์ `เช็คแต้ม` เพื่อดูการ์ด VIP ทอง/เงิน/ทองแดง ได้ทันที

## 4. กระบวนการจัดส่งพัสดุ (Smart Logistics Flow)
- แอดมินกรอกหมายเลขพัสดุ (เช่น KERRY-9999) ในหน้า Admin Dashboard
- ระบบส่งการ์ด **สถานะการจัดส่ง** ให้ลูกค้า
- ลูกค้ากดปุ่ม "เช็คพัสดุ Kerry" ระบบจะพาลูกค้าไปหน้าเว็บ KEX Express พร้อมเช็คสถานะพัสดุให้อัตโนมัติ

## 5. กระบวนการปรึกษาปัญหาทางเทคนิค (AI Mechanic Flow)
- ลูกค้าพิมพ์คำถามโดยมีคำว่า **"ถาม"** นำหน้า (เช่น `ถาม รถไถสตาร์ทไม่ติด`)
- บอทส่งคำถามให้ Gemini 1.5 Flash วิเคราะห์สาเหตุ
- บอทตอบกลับลูกค้าด้วยข้อความที่เป็นมืออาชีพและตรงประเด็น เสมือนคุยกับช่างผู้ชำนาญการ
